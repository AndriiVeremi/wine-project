# Wine Project

Інформаційно-навігаційна веб-платформа для дослідження винної індустрії, створена як дипломний проєкт.

## 📜 Опис

Платформа надає користувачам можливість досліджувати та відкривати для себе світ вина. Вона містить інформацію про різні сорти, регіони, виробників та надає зручні інструменти для навігації та пошуку.

## ✨ Основні можливості

*   **Каталог вин:** Детальна інформація про вина, включаючи ціну.
*   **Розумний пошук та фільтрація:** Зручні інструменти для пошуку та фільтрації.
*   **Профілі користувачів:** Можливість зберігати улюблені вина та створювати колекції.
*   **Аутентифікація:** Безпечна реєстрація та вхід через Firebase.
*   **VIP-статус для виноробень:** Можливість для виноробень отримати VIP-статус для пріоритетного відображення у пошуку.

## 🛠️ Технологічний стек

| Призначення | Технології |
| :--- | :--- |
| **Frontend** | Vite, React, TypeScript, React Query, Zustand, Axios, React Router, styled-components, Firebase, react-hot-toast, react-icons, Vitest |
| **Backend** | Node.js, Express, TypeScript, Mongoose, Swagger, Joi, Helmet, Firebase Admin, Google Generative AI, CORS, express-rate-limit, Jest |
| **База даних** | MongoDB (MongoDB Atlas) |
| **Аутентифікація** | Firebase Authentication |
| **CI/CD** | GitHub Actions |
| **Якісність коду** | ESLint, Prettier |
| **Інфраструктура** | Docker, Docker Compose |
