# Функціональність проєкту

Документ описує всі основні функції Wine Project.

---

## Каталог вин

### Перегляд вин
- Список всіх вин з пагінацією
- Фільтрація за параметрами:
  - **Колір**: червоное, біле, рожеве, помаранчеве
  - **Солодкість**: сухе, напівсухе, напівсолодке, солодке
  - **Регіон**: вибір з випадаючого списку
  - **Сорт винограду**: фільтрація по сорту
  - **Рейтинг**: мінімальний рейтинг (3, 4, 5)
  - **Вінтаж**: рік врожаю
- Відображення ціни кожного вина
- Відображення середнього рейтингу

### Детальна сторінка вина
- Повна інформація про вино
- Опис та дегустаційні нотатки (підтримка HTML-форматування)
- Інформація про виноробню
- Форма додавання відгуку
- Список відгуків інших користувачів
- Кнопка "додати до улюблених"
- **Слайдер подібних вин**: відображає топові вина того ж кольору та солодкості

### Улюблені вина
- Збереження вин в персональний список
- Швидкий доступ до улюблених вин в профілі

---

## Каталог виноробень

### Перегляд виноробень
- Список виноробень з пагінацією
- Відображення VIP-виноробень на початку списку
- Фільтрація за рейтингом та країною
- Відображення логотипу, рейтингу, кількості відгуків

### Детальна сторінка виноробні
- Повна інформація про виноробню
- Історія виноробні (Rich Text)
- Контактна інформація
- Геолокація на мапі (Leaflet)
- Галерея зображень
- **Слайдер вин**: відображає бестселери цієї виноробні
- Список турів
- Відгуки

### VIP-статус
- Можливість отримання VIP-статусу (тільки через адміністратора)
- VIP-виноробні відображаються першими у пошуку
- Спеціальний бейдж для VIP-виноробень

### Управління для власника
- Редагування даних виноробні
- Додавання/редагування вин
- Додавання/редагування турів
- Завантаження логотипу та галереї
- **Rich Text Editor (Tiptap)**: професійне форматування історії виноробні (жирний, курсив, списки, вирівнювання)

## Каталог сортів винограду

### Перегляд сортів
- Список всіх сортів винограду
- Карточки з зображенням та основною інформацією

### Детальна сторінка сорту

- Додавання нових сортів винограду
- Редагування інформації про сорти

## Відгуки та рейтинги

### Система рейтингів
- Оцінка від 1 до 5 зірок
- Використання компонента `RatingStars`

### Створення відгуку
- Вибір рейтингу
- Написання тексту відгуку
- **Rich Text Editor (Tiptap)**: можливість форматування тексту відгуку (жирний, курсив, списки тощо)

### Відгуки про:
- Вина
- Виноробні
- Тури

### Модерація (для адміністраторів)
- Перегляд всіх відгуків
- Видалення неприйнятних відгуків
